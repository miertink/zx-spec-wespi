Instalar o ZX-Spec Wespi

Servidor de fitas WiFi para a família ZX Spectrum, num ESP32. Grave o programa no seu ESP32 direto pelo navegador: sem instalar nada, sem programar.

Você vai precisar de

  • Uma placa ESP32 DevKit (ESP32-WROOM, 4 MB de flash).
  • Um cabo USB de dados (alguns cabos só carregam: se a porta não aparecer, troque o cabo).
  • Um computador com Chrome ou Edge (Windows, Mac ou Linux). Firefox e Safari não servem para este método.

Passo a passo

  1. Ligue o ESP32 no computador pelo cabo USB.
  2. Clique em Instalar abaixo e escolha a porta do ESP32 na lista (aparece como CP210x, CH340 ou USB Serial).
  3. Confirme e espere uns 2 minutos, até a mensagem de instalação concluída. Na primeira vez, aceite apagar o dispositivo.
Este navegador não grava no ESP32. Use o Chrome ou o Edge num computador, ou veja a alternativa abaixo. A instalação só funciona numa página https.
  1. Monte a interface (dois resistores, um capacitor e dois cabos de áudio): veja o esquema.
  2. Ligue o Spectrum e digite LOAD "". Quando o menu aparecer, tecle W, escolha a sua rede WiFi e digite a senha.
  3. Tecle SPACE no menu para ver o endereço web do ESP32. Abra-o no navegador e envie as suas fitas (.tap, .tzx, .pzx, .csw).

Se algo não funcionar

  • A porta não aparece: instale o driver da sua placa, CP210x ou CH340 (o nome está no chip perto do conector USB), e troque o cabo se precisar.
  • Não conecta: segure o botão BOOT da placa, clique em Instalar e solte o botão quando a gravação começar.
  • Reinstalar ou atualizar: as fitas ficam no ESP32, mas a rede WiFi e o idioma voltam ao padrão: escolha a rede de novo com W no menu.

Sem Chrome ou Edge

Baixe o arquivo zx-spec-wespi.bin (também nas versões) e grave-o no endereço 0x0 com o Flash Download Tool da Espressif (Windows): um único arquivo.

Install ZX-Spec Wespi

WiFi tape server for the ZX Spectrum family, on an ESP32. Put the program on your ESP32 straight from the browser: nothing to install, no programming.

You will need

  • An ESP32 DevKit board (ESP32-WROOM, 4 MB flash).
  • A USB data cable (some cables only charge: if the port does not show, try another cable).
  • A computer with Chrome or Edge (Windows, Mac or Linux). Firefox and Safari cannot do this.

Step by step

  1. Connect the ESP32 to the computer with the USB cable.
  2. Click Install below and pick the ESP32's port in the list (shown as CP210x, CH340 or USB Serial).
  3. Confirm and wait about 2 minutes, until it says the installation is complete. The first time, accept to erase the device.
This browser cannot program the ESP32. Use Chrome or Edge on a computer, or see the alternative below. Installing only works from an https page.
  1. Build the interface (two resistors, one capacitor and two audio cables): see the schematic.
  2. Turn the Spectrum on and type LOAD "". When the menu shows, press W, pick your WiFi network and type its password.
  3. Press SPACE in the menu to see the ESP32's web address. Open it in a browser and upload your tapes (.tap, .tzx, .pzx, .csw).

If something does not work

  • No port shows: install your board's driver, CP210x or CH340 (the name is on the chip next to the USB connector), and try another cable if needed.
  • It does not connect: hold the board's BOOT button, click Install and let go once writing starts.
  • Installing again or updating: the tapes stay on the ESP32, but the WiFi network and the language go back to the defaults: choose the network again with W in the menu.

Without Chrome or Edge

Download zx-spec-wespi.bin (also under releases) and write it at address 0x0 with Espressif's Flash Download Tool (Windows): a single file.
